# hustincao.com

A minimal React app powered by Vite.

## Commands

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run lint` checks the source with ESLint.
- `npm run preview` serves the production build locally.
- `npm run deploy` builds and publishes the site to GitHub Pages.

## Deployment

The site is published from the `gh-pages` branch at
[hustincao.github.io](https://hustincao.github.io). Run `npm run deploy` from
`main` to build the latest source and publish it.
